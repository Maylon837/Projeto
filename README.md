# Site Informativo sobre ESG

Site desenvolvido em **PHP** com o objetivo de explicar o conceito de ESG (Environmental, Social and Governance), suas práticas e o impacto nas empresas e na sociedade.

## 📋 Sobre o Projeto

Este projeto foi criado para apresentar de forma clara e acessível:

- O que é ESG
- Para que serve
- Como funciona na prática
- Qual o impacto nas empresas e na vida das pessoas

O site foi desenvolvido em dupla com uma colega de faculdade, como parte das atividades acadêmicas.

## 🚀 Funcionalidades

- Páginas informativas sobre ESG
- Conteúdo explicativo e organizado
- Estrutura com HTML, CSS, JavaScript e PHP
- Navegação entre as seções do site

## 🛠️ Tecnologias Utilizadas

- PHP
- HTML5
- CSS3
- JavaScript
